
Assignment Name: Image Filter Lab
Aim:
Use OpenCV to grayscale, blur, detect edges and show before/after.
Objective:
Apply basic image processing techniques using OpenCV to transform and analyze images.

Python Program:

import cv2

# Load image
image = cv2.imread('sample.jpg')   # replace with your image path

# Check if image loaded
if image is None:
    print("Error: Image not found")
    exit()

# Resize for better display (optional)
image = cv2.resize(image, (500, 400))

# 1. Grayscale
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 2. Blur (Gaussian Blur)
blur = cv2.GaussianBlur(image, (7, 7), 0)

# 3. Edge Detection (Canny)
edges = cv2.Canny(image, 100, 200)

# Show images
cv2.imshow("Original Image", image)
cv2.imshow("Grayscale Image", gray)
cv2.imshow("Blurred Image", blur)
cv2.imshow("Edges Detected", edges)

# Wait and close
cv2.waitKey(0)
cv2.destroyAllWindows()

Explanation:
Original Image → Normal image
Grayscale → Removes color, keeps intensity (black & white)
Blur → Smooths image, reduces noise
Edges → Highlights object boundaries

Output:

You will see 4 windows:
Original
Grayscale
Blurred
Edge detected
