Algorithm:
Start the program
Import pandas,sklearn libraries
Create dataset manually

Predict marks for given study hours
Display results
Stop

Python Program:

import pandas as pd
from sklearn.linear_model import LinearRegression

# Create dataset
data = {
    "Study_Hours": [1, 2, 3, 4, 5, 6, 7, 8],
    "Marks": [35, 40, 50, 55, 65, 75, 85, 95]
}

df = pd.DataFrame(data)

print("Dataset:")
print(df)

# 1. Identify features and label
X = df[["Study_Hours"]]   # Feature
y = df["Marks"]           # Label

# 2. Train model
model = LinearRegression()
model.fit(X, y)

# 3. Predict marks for 9 study hours
predicted_marks = model.predict([[9]])

print("\nPredicted Marks for 9 Study Hours:", predicted_marks[0])
