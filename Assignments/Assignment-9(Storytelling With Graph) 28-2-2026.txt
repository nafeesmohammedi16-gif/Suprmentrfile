
Assignment Name: Storytelling with Graph
Aim:
Create bar chart, pie chart, histogram and write a short data story explaining trends.
Objective:
To visualize data using different types of graphs (Bar Chart, Pie Chart, Histogram) and explain trends using a short data story.
Dataset Used (Sample Data):

Student Marks (Out of 100)
 Subject    Marks 

 Maths      85    
 Physics    78    
 Chemistry  88    
 English    72    
 Computer   95    

Extra Data for Histogram (Test Scores of 20 Students)
[45, 56, 67, 78, 89, 90, 34, 76, 88, 92, 61, 73, 84, 59, 68, 77, 81, 69, 74, 85]

Algorithm:
Import matplotlib libraries.
Create data for subjects and marks.
Plot bar chart for subject-wise comparison.
Plot pie chart to show percentage distribution.
Plot histogram to show marks distribution range.
Display all graphs.
Write observations and data story.

Python Program:

import matplotlib.pyplot as plt

# Bar Chart Data
subjects = ['Maths', 'Physics', 'Chemistry', 'English', 'Computer']
marks = [85, 78, 88, 72, 95]

# 1. Bar Chart
plt.figure()
plt.bar(subjects, marks)
plt.title("Subject-wise Marks")
plt.xlabel("Subjects")
plt.ylabel("Marks")
plt.show()

# 2. Pie Chart
plt.figure()
plt.pie(marks, labels=subjects, autopct='%1.1f%%')
plt.title("Marks Distribution")
plt.show()

# 3. Histogram
scores = [45, 56, 67, 78, 89, 90, 34, 76, 88, 92, 61, 73, 84, 59, 68, 77, 81, 69, 74, 85]

plt.figure()
plt.hist(scores, bins=5)
plt.title("Marks Distribution Histogram")
plt.xlabel("Marks Range")
plt.ylabel("Number of Students")
plt.show()

Sample Output:
Bar chart shows highest marks in Computer (95).
Lowest marks are in English (72).
Pie chart shows Computer contributes highest percentage.
Histogram shows most students scored between 70–90 marks.

Data Story:

The visualizations reveal that the student performs strongest in Computer and Chemistry, while English is the comparatively weakest subject. 
The histogram indicates that most students scored in the 70–90 range, suggesting overall good academic performance. 
Very few students scored below 50, which shows that failure rate is low. Overall, the class performance trend is above average with a strong inclination 
toward technical subjects.
