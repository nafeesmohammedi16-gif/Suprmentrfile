
Assignment Name: Password Authentication using Python Loop
Aim:
To create a password authentication system using loop in Python.
Objective:
Write a program to create a strong password.
Algorithm:
Start the program
Set a correct password
Set number of attempts (3)
Use a loop to ask user to enter password
Check entered password with stored password
If correct → Display success message and stop
If incorrect → Reduce attempts and show remaining attempts
If attempts become 0 → Lock the system
End program

python code:

password = "Smvce0633"
attempts = 3

while attempts > 0:
    enter_password = input("Enter password: ")

    if enter_password == password:
        print("Access granted.")
        break
    else:
        attempts -= 1
        print("Wrong password. Attempts left: ")

if attempts == 0:
    print("Account locked.")
The above code is strong password code which is built using basic python loops.

Output:
Enter password: Smvce0633
Access granted
